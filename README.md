# 🏎️ Carz - Luxury & Supercar Showcase Website

A landing page built with **HTML5** and custom **CSS3**. Designed to showcase high-performance luxury car models, featuring an embedded video hero section, interactive model cards with pricing, an about section, and a full footer navigation.

## ✨ Key Features
* **Navigation Bar:** Fixed header with logo, section menu links, and social media icons.
* **Hero Section:** Bold landing screen with call-to-action text.
* **Embedded Video:** Video banner showcasing featured luxury supercars.
* **Car Models Grid:** Catalog displaying top models (Lamborghini, Ferrari, Porsche, Audi, Mustang, etc.) with pricing in INR and booking links.
* **Company About Section:** Information about the dealership's services and mission.
* **Comprehensive Footer:** Structured links for contact options, social channels, and legal policies.

## 🛠️ Built With
* **HTML5** (Semantic page structure)
* **CSS3** (Custom styling, flex layouts, typography)
* **Font Awesome** (Social media vector icons)
